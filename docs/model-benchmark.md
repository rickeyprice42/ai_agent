# Benchmark локальных моделей Avelin

Этот benchmark сравнивает модели на одном фиксированном наборе из 36 задач Avelin:
русский язык, строгий JSON, выбор инструментов, агентные инструкции и удержание
контекста. Он не заменяет пользовательское тестирование, но не позволяет выбирать
модель только по рекламным описаниям.

## Воспроизводимый запуск

Требования: запущенная Ollama, заранее загруженные модели и Python 3.11+.

```powershell
python scripts/benchmark_models.py --dry-run
python scripts/benchmark_models.py --model qwen3:1.7b --model qwen3:4b-instruct
```

Для удалённой Ollama можно передать `--base-url`. Ключ читается только из переменной
`OLLAMA_API_KEY`, чтобы он не попадал в историю команд и список процессов.

Условия сравнения фиксированы: `temperature=0`, `seed=42`, reasoning выключен,
окно контекста 8192 и не более 256 выходных токенов.
Модели запускаются последовательно, чтобы не делить 4 ГБ VRAM между процессами.
Отчёты JSON, CSV и Markdown записываются в `reports/benchmarks/` и содержат hash
набора задач, точность, скорость, задержку, ошибки и пиковую занятую VRAM.

## Кандидаты для GTX 1650 Ti 4 ГБ

| Модель | Размер Ollama | Лицензия | Решение до измерений |
|---|---:|---|---|
| `qwen3:1.7b` | 1.4 ГБ | Apache 2.0 | Базовый быстрый кандидат |
| `qwen3:4b-instruct` | 2.5 ГБ | Apache 2.0 | Основной кандидат по качеству |
| `phi4-mini` | 2.5 ГБ | MIT | Следующий кандидат для сравнения |
| `llama3.2:3b` | 2.0 ГБ | Llama 3.2 Community | Резерв; русский не в официальном списке поддерживаемых языков |
| `gemma3:4b` | 3.4 ГБ | Gemma Terms | На границе VRAM, вероятен CPU offload |
| `gpt-oss:20b` | 14 ГБ | Apache 2.0 | Не подходит для локального запуска на 4 ГБ VRAM |

Версии, ссылки на первичные источники и hardware-fit хранятся в
`benchmarks/models.json`. До локального прогона размер и контекст считаются
заявленными поставщиком, а не измеренным результатом.

## Правило выбора

Основной локальной моделью становится не абсолютный лидер, а лучшая модель без
ошибок запуска, которая помещается на целевой машине и даёт приемлемый баланс
точности, скорости и VRAM. Облачные модели сравниваются отдельно: их нельзя
выдавать за локальный результат.

## Измеренный результат на целевой машине

| Модель | Score | Tool calling | Context | Median latency | tokens/s | Решение |
|---|---:|---:|---:|---:|---:|---|
| `qwen3:4b-instruct` | 0.806 | 0.900 | 1.000 | 2464 ms | 16.619 | Основная локальная модель |
| `qwen3:1.7b` | 0.708 | 1.000 | 0.750 | 417 ms | 95.385 | Быстрый резерв |
| `phi4-mini` | 0.556 | 0.100 | 1.000 | 3344 ms | 19.531 | Не использовать как агентное ядро |

У всех прогонов 0 runtime-ошибок. Полная таблица решений и ссылки на raw reports:
`reports/benchmarks/summary.md`.
