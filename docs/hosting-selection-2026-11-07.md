# Выбор первого VPS для Avelin — 7 ноября 2026

Бюджет пользователя: 1 000–2 000 ₽/месяц без оплаты модельных API.
Зарубежная карта доступна. Это сравнение публичных условий; сервер не заказан,
проверка регистрации и реальная нагрузочная проверка провайдеров не выполнялись.

## Ресурсы

По текущему коду предпочтителен x86-64 VPS: 4 vCPU, 8 ГБ RAM, от 60–80 ГБ SSD,
Ubuntu 24.04 LTS. Минимум для личного пилота — 2 vCPU/4 ГБ с ограничением
одновременных браузеров и тяжёлых задач. Это оценка, а не Linux-бенчмарк.
Инференс остаётся в облачных API. Сайт, API и небольшую очередь задач можно
первоначально разместить на одном VPS.

## Предварительный выбор

**Netcup Lite 2 — первый кандидат по опубликованным ресурсам и цене**, если
провайдер подтвердит возможность регистрации с настоящими данными пользователя
и подходит оплата за три месяца. Доказанного сравнительного преимущества по
скорости/надёжности у нас пока нет. [Проверка личности Netcup](https://www.netcup.com/en/helpcenter/documentation/general/identity-verification)
может потребовать документы; зарубежная карта сама по себе не гарантирует
допуск аккаунта. OVH — конкурент после подтверждения конечной цены/срока заказа.

Для проверки без трёхмесячного обязательства VDSina 4 ГБ можно рассматривать
как более скромный по памяти суточный пилот. Копии БД и файлов хранить отдельно
от VPS; стоимость этого хранилища ещё не зафиксирована.

Страна VPS не отменяет условий API. В [официальном списке OpenAI](https://developers.openai.com/api/docs/supported-countries)
Россия отсутствует, а доступ вне поддерживаемых регионов ограничен.
Допустимость аккаунта и предоставления доступа пользователям проверяется отдельно;
зарубежный IP не является гарантией соответствия условиям провайдера.

## Подготовка приложения до переноса — AVE-60

- `src/ai_agent/tools/browser.py` пока проверяет Windows-пути Edge и использует
  `channel="msedge"`; нужен Linux Chromium runner и настоящий smoke-test.
- Отдельный серверный профиль зависимостей; Windows desktop UIA остаётся
  возможностью локального Windows-исполнителя.
- Статическая production-сборка frontend, HTTPS/reverse proxy, сервисный запуск
  backend и контролируемое количество worker-процессов.
- Общие лимиты браузеров/изображений/долгих задач: текущий chat limit 8 не является
  результатом теста на небольшом VPS.
- Рабочая БД — SQLite. PostgreSQL-контракт в migrations ещё не является
  работающим адаптером; не менять DATABASE_FILE на DSN без реализации.
- Независимый backup **БД и файлов**, восстановление и quotas. Нынешний
  `scripts/backup_local_data.py` сохраняет только SQLite.
- После тестового развёртывания: API/streaming/background/restart/HEIC/Playwright/
  push/изоляция аккаунтов и нагрузка. Затем AVE-61 — обновления и rollback.

Окончательного выбора и оплаты нет. Инциденты, цены, наличие и условия
регистрации необходимо перепроверить перед фактическим заказом.
