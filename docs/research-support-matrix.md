# Browser Research support matrix

`research_read` не обещает универсальный доступ к любому сайту. Он работает только
с публичными страницами без пользовательской сессии и возвращает evidence вместе с
URL, временем чтения, locale/region, confidence и SHA-256 каждого цитируемого фрагмента.

| Тип источника | Поддержка | Поведение |
|---|---|---|
| Статический HTML, `main`/`article` | Да | Bounded HTTP, очистка навигации и cookie boilerplate |
| JSON и JSON-LD | Да | Структурированные поля сохраняются в evidence |
| Таблицы и списки | Да | Извлекаются отдельно от основного текста |
| SPA/JavaScript | Ограниченно | Изолированный headless Edge fallback; иначе `unsupported_dynamic_page` |
| Ошибка HTTP transport/TLS | Fallback | Edge проверяет TLS самостоятельно; валидация сертификатов остаётся включённой |
| Превью изображений | References | До 100 URL/alt/контекстов строки таблицы; ссылки не подтверждают содержимое изображения |
| Apple Books | Adapter | Только прямая карточка `books.apple.com/<region>/book/...` |
| Apple TV | Adapter | Только прямая карточка `tv.apple.com/<region>/movie|show/...` |
| Apple TV+ availability | Fail closed | Нужна явная поддержка подписки на самой карточке |
| Login / личная сессия | Нет | `requires_login`; cookies и пароли пользователя недоступны |
| Paywall | Нет | `paywall` |
| CAPTCHA / anti-bot | Нет | `anti_bot`, без обхода защиты |
| Robots / legal policy | Нет | `robots_or_policy` |
| Private/local network | Нет | `private_network_blocked` до запроса |
| Файлы и бинарные downloads | Нет | `download_blocked` |
| Ответ сверх лимита | Нет | `response_too_large` |

Всё содержимое страницы считается недоверенными данными. Обнаруженная prompt
injection помечается в `safety.prompt_injection_detected`, не меняет план агента и
не даёт странице права вызывать инструменты.

Поиск обнаруживает URL через DuckDuckGo Lite; при транспортной ошибке, пустой выдаче
или anti-bot странице допускается один fallback на Bing RSS. CAPTCHA не решается;
после challenge провайдер пропускается в течение пяти минут в текущем экземпляре.
Официальный Apple Search API остаётся первым источником обнаружения книг. Выдача
каждого провайдера проходит одинаковый фильтр; snippets не подтверждают итоговые факты.
Оба бесплатных поисковых интерфейса могут быть недоступны или вернуть нерелевантные
данные. Это явно отражается в результате; универсальный надёжный поиск не гарантирован.

Reader сохраняет основной текст, даты, авторов и данные конкретной карточки.
`articleBody` переносится в основной текст, когда это полноценная статья; повторное
включение того же текста в JSON-LD убирается. `content_limits` и
`main_text_truncated` показывают границы извлечения. При нехватке контекста старые
tool results сокращаются раньше новых: JSON остаётся валидным, URL/даты/авторы/цены
сохраняются, текстовые выдержки содержат точные интервалы исходного текста.
Факты из пропущенных участков нельзя считать прочитанными.

Полный screenshot каталога из сотен строк при уменьшении для vision теряет детали.
Для сравнения превью нужно открывать конкретный image URL или использовать
`screenshot_full_page=false` для текущего viewport. Обычный режим полного screenshot
сохранён для совместимости. Анализ созданного браузером изображения по-прежнему
требует отдельного разрешения: разрешение на пользовательское фото не переносится на него.
