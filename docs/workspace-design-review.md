# Workspace: проверка интерфейса 29.10.2026

Ориентир — вариант Workspace из `avelin-design-directions.html`. Реализация выполнена в рамках AVE-56 и прошла визуальную приёмку владельца проекта.

## Что сохранено и доработано

- Компактная навигация, отдельные страницы проектов, памяти, автоматизаций, задач, файлов и настроек. На главной — новый запрос, последние диалоги и активность из данных пользователя.
- Системные шрифты без внешней загрузки, сдержанное выделение активного раздела, согласованные размеры текста и элементов, светлая и тёмная темы. Вход и регистрация приведены к той же системе; убраны технические описания и неработающие кнопки OAuth.
- Исправлена сетка чата: мобильная кнопка списка диалогов больше не становится третьей ячейкой desktop-сетки из-за каскада CSS.
- Чат занимает доступную высоту окна. История прокручивается отдельно, поле ввода остаётся доступным в длинном диалоге и низком окне. На телефоне список диалогов открывается отдельным представлением внутри чата.
- Длинные названия, пути, ссылки и разрешения не растягивают страницу. Таблицы и блоки кода имеют собственную горизонтальную прокрутку; изображения ограничены шириной ответа. Карточки файлов доступны для скачивания и из чата, и из раздела «Файлы».
- Мобильное меню удерживает фокус, изолирует основное содержимое через `inert`, закрывается по Escape и возвращает фокус. Переход к desktop-сетке снимает блокировку прокрутки. Поля на телефоне используют размер текста 16 px; добавлены safe-area отступы и настройки viewport.
- Автопрокрутка не возвращает пользователя вниз при чтении предыдущих сообщений. Возврат в чат и отправка запроса открывают последние сообщения. На устройствах с сенсорным указателем завершение ответа не фокусирует поле ввода автоматически.
- Исправлено обращение к уже очищенной переменной исключения в отложенном диалоге ошибки лаунчера.

Автотест использует установленный Edge в отдельном временном профиле и синтетические данные. Он не читает рабочие чаты, не создаёт пользователей, не обращается к моделям и не расходует API-кредиты. Изменение размеров окна не является проверкой системного DPI или настоящей мобильной клавиатуры. Управление пользовательским браузером через computer-use в текущих настройках недоступно.

Итоговые снимки главной в обеих темах, настроек, мобильной главной, чата, регистрации и ошибки просмотрены вручную по изображениям. Наличие автоматических проверок не гарантирует отсутствие всех различий между браузерами.

## Повторный запуск

Из `frontend`:

```powershell
pnpm build
```

Из корня репозитория:

```powershell
.\.venv\Scripts\python.exe scripts\verify_workspace_ui.py
.\.venv\Scripts\python.exe -m unittest tests.test_launcher -v
.\.venv\Scripts\python.exe scripts\launch_local.py --check
git diff --check
```

Браузерный тест запускает свой Vite preview на `127.0.0.1:4179` и завершает его после проверки. Актуальный результат — `.local/workspace-review/results.json`; перечень переполнений — `layout-failures.json`. Скриншоты и журнал preview находятся рядом и исключены из Git. Файлы `overflow-*` могут сохранять снимки ранее найденных дефектов; актуальным источником статуса являются JSON-отчёты последнего запуска.

Проверка на реальных iPhone/Android и с настоящей экранной клавиатурой переносится в AVE-59, где появится безопасный удалённый preview. Публичный сайт, маршрутизация Download/Auth и production-развёртывание относятся к следующим задачам roadmap.
